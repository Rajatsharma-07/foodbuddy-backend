# foodbuddy-backend

## Steps to run the project locally

- Clone the repository on your local machine. 
  ``` bash
  git clone https://github.com/Rajatsharma-07/foodbuddy-backend.git

- Enter into your project folder
  ```bash
  cd foodbuddy-backend

- Install all the packages
  ```bash
  yarn install

- Create a new file .env and copy the content from env.sample into this file.

- Run your project
  ```bash
  yarn start:dev

- Your backend application is running on `http://localhost:5001`.

Happy Coding!
